# Kertas

A personal iLovePDF-style PDF toolkit for iPhone. Everything runs on the phone.

- Scan to PDF with automatic edge detection and perspective correction (camera or photos)
- Merge, split, remove, extract, organise, rotate, crop
- Compress, repair, OCR
- JPG, Word, PowerPoint, Excel and HTML to PDF; PDF to JPG, images, text and Markdown
- Edit PDF with font detection and Google Fonts download, add text, images, drawings, highlights, notes
- Sign, protect, unlock, redact, compare, page numbers, watermark, forms
- On-device AI summary (Apple Intelligence) and translation

Built by GitHub Actions into an unsigned IPA for sideloading. The IPA is attached to each release.
